# Dallet

Офлайн-учёт личных денег в ТМТ (туркменский манат): счета, операции, категории, аналитика.

Текущая версия: **0.0.8** (`versionCode` 8). Ещё → Безопасность: PIN-код (4 цифры) и вход по отпечатку, запрашиваются при запуске; забытый PIN можно только сбросить вместе с данными (поэтому сначала делайте Экспорт). На графике «Расходы по времени» над столбцами показаны суммы. Минималистичный чёрно-бело-серый дизайн, шрифт Inter, обновлённая главная (баланс, доходы/расходы за месяц, счета в ряд, последние расходы с иконками). CI собирает оптимизированный release-APK (R8), подписанный тем же ключом, — прокрутка заметно плавнее, чем в debug.

## Что умеет

- Онбординг: стартовые остатки «Наличные» и «ЗП карта»
- Главная: общий баланс, остатки по счетам, последние 10 расходов
- «+»: Доход, Расход, Перевод (с датой и клавиатурой без перекрытия полей)
- История: все операции, правка и удаление
- Аналитика: доходы/расходы за неделю, месяц или год; donut расходов по категориям; поток расходов по времени
- Ещё → Счета и Категории (цвет + сетка графических иконок)
- Ещё → Данные: **Экспорт** (резервная копия в JSON-файл), **Импорт** (полная замена данных из файла; также кнопка «Восстановить из файла» на первом запуске), **Сбросить всё** (с вводом слова «СБРОС»)
- Тема как в системе телефона; интерфейс на русском

## Сборка APK (GitHub Actions)

После push в `main` откройте **Actions → Build Dallet APK → Artifacts → `Dallet-<versionName>`** (файл `Dallet-0.0.3.apk` и т.п.). Версию бампите вручную в `app/build.gradle.kts` (`versionName` / `versionCode`) перед значимым релизом.

Debug APK подписывается **одним стабильным keystore** из GitHub Secrets — обновление поверх предыдущей CI-сборки не требует удаления приложения и сохраняет данные (счета, категории, операции).

### Secrets (один раз)

Нужны секреты репозитория:

| Secret | Значение |
|--------|----------|
| `DALLET_DEBUG_KEYSTORE_BASE64` | `base64` от файла `.jks` |
| `DALLET_DEBUG_STORE_PASSWORD` | пароль хранилища |
| `DALLET_DEBUG_KEY_PASSWORD` | пароль ключа (для PKCS12 обычно = store password) |
| `DALLET_DEBUG_KEY_ALIAS` | alias (например `dallet_debug`) |

Сгенерировать keystore локально (не коммитить):

```bash
keytool -genkeypair -v \
  -keystore keystore/dallet-debug.jks \
  -alias dallet_debug \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass 'YOUR_STORE_PASSWORD' \
  -keypass 'YOUR_KEY_PASSWORD' \
  -dname 'CN=Dallet Debug,O=Dallet,C=TM'

base64 -w0 keystore/dallet-debug.jks   # Linux/macOS
# PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes('keystore/dallet-debug.jks'))
```

Положить значения в **Settings → Secrets and variables → Actions**.

> Если на телефоне уже стоит APK со **старой** (случайной) подписью, первый переход на стабильный ключ потребует одну переустановку. Дальше данные при обновлениях сохраняются.

Локально (опционально):

```powershell
gradle wrapper --gradle-version 8.7
./gradlew :app:assembleDebug
```
